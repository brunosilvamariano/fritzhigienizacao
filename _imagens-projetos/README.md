# Imagens conceituais — Traço

24 imagens originais geradas por IA com a ferramenta integrada de imagens do Codex, para um portfólio conceitual de marcenaria. Não representam obras executadas pela empresa.

Entrega: WebP, 2048 × 1365 px, paisagem aproximadamente 3:2. Os PNGs originais foram preservados na pasta de imagens geradas do Codex; os arquivos desta pasta foram redimensionados e convertidos com sharp.

| Projeto | Ambiente             |
| ------- | -------------------- |
| 01      | Cozinha ampla        |
| 02      | Cozinha compacta     |
| 03      | Quarto principal     |
| 04      | Sala de estar        |
| 05      | Banheiro             |
| 06      | Escritório integrado |

Cada projeto contém `capa`, `angulo`, `meio` e `detalhe`. O prompt do segundo ângulo foi complementado com uma vista alternativa de três quartos. As capas foram geradas sem referências anteriores e as edições usaram somente a capa do próprio ambiente. A ferramenta integrada não oferece criação de conversas separadas.

Revisão visual durante a geração: divisões da marcenaria, ferragens, continuidade de madeira e pedra, ausência de textos e reflexos humanos. Inscrições em livros e a divisão de gavetas do banheiro foram corrigidas antes da entrega.

Todos os 24 WebPs tiveram nomes, formato, dimensões e decodificação conferidos. Prompts finais registrados em `prompts.json`.
